How to load these onto a calculator

  1. Open SourceCoder 3 (free, in-browser).
  2. Paste a program's text, then export it as an .8xp file.
  3. Send the .8xp to your calculator with TI Connect CE and a USB cable.
  4. On the calculator: PRGM → choose the program → ENTER.

Everything is written to run on the original TI-82, so it also works on the 83/83+/84+ unchanged.
